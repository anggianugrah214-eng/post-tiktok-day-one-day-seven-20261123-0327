An original 24-second vertical TikTok video about "Ghost Hop", a tiny agent-built platformer, on the day it was made and after a week of daily updates: the same map and the same start, cut between day one (one ghost, one jump, one coin) and day seven (coins, enemies, a flag, a sunset sky and a score HUD), closing on the newer build and make.fun's referral end card with the account's own referral code. The video is posted publicly on TikTok; `VIDEO.json` names it, and `main.ts` hands that address to the gate. Places go by the video's views and interactions.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
